=============================
Bayeux 3.5.5 Release Notes
=============================

Bayeux 3.5.5  adds some  new features  as well as  fixes for  bugs and
reported issues.

For information on  changes made in previous versions,  please see the
`release notes archive`_.

.. _`release notes archive` : archived_notes/index.rst

Requirements
============

* Bayeux  3.5.5 requires  Linux (Ubuntu >=18.04, preferred
  20.04, CentOS >=7.5), or macOS 10.
* Bayeux 3.5.5 depends on BxDecay >=1.1.2.
